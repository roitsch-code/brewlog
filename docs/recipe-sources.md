# Recipe sources — the verified list

Compiled 2026-10-19 for the recipe scout (`scripts/recipe-scout.mjs`). Every URL below was fetched from a session runner on that day; `verified: no` means the fetch failed or the page carried no recipe text, and says why. Nothing on this page is from memory. Numbers quoted in the notes are what the fetched page said, written down for orientation — a corpus entry still needs its own in-session cross-check (CLAUDE.md, never fabricate).

**Legend.** *Read via* = how the runner got the text: `direct` (plain HTTPS with a browser user agent), `reader` (`https://r.jina.ai/<url>`), `reader+retry` (Cloudflare sites answer "Just a moment" sometimes — send `X-No-Cache: true` and retry up to 3×), `RSS feed`, `PDF` (needs `pdftotext`), `API key` (needs a credential the owner creates). *Numbers* = dose / water / temperature / pour clock present in the page TEXT (not an image, not a video). *Corpus* = a recipe by this person or from this host is already in `src/lib/knowledge/recipes/` (155 recipes, 92 attributed persons, 26 source hosts on 2026-10-19 — counted with the validator bundle, not from memory).


## 0. What works from the runner — and what does not

Findings from 237 source rows (own 72-URL checker plus four research passes, each row one or more fetches), the part the scout must know before any source:

- **Plain pages:** most roaster, maker and magazine pages answer a `curl` with a Chrome user agent. Shopify shops rate-limit bursts (`429`) — one request per page, retry after a pause (Stumptown, Counter Culture, The Barn, Right Side, 3fe, Market Lane, Onibus, Drop, Square Mile Switch page, Hario Europe homepage).
- **Cloudflare "Just a moment" sites** (European Coffee Trip, Barista Hustle, Clive Coffee, Fellow `/blogs/learn` intermittently, 19grams index, Perfect Daily Grind sometimes): direct is `403`; the reader proxy with `X-No-Cache: true` and up to 3 retries got every European Coffee Trip recipe page open today (Wölfl, Peng, Fukahori 2018 + Switch) — one page (the 2021 AeroPress recipe) stayed walled after 3 tries. Per-URL luck, so the scout retries and moves on, never marks the page dead.
- **YouTube:** the channel pages answer `200` direct, but `watch` pages now bounce the runner to a Google "sorry" page. Through the reader, a `watch` page returns the **full description and the top comments** — James Hoffmann's "A Better 1 Cup V60" description carries the whole recipe (15 g : 250 g, 50 g bloom, 100/150/200/250 g at 0:45/1:10/1:30/1:50, ~3:00). Only creators who WRITE the recipe into the description are scoutable this way: Hoffmann yes; Lance Hedrick, Kyle Rowsell, Matt Winton, Hario's own channel no (checked, descriptions without numbers). The reliable path is the **YouTube Data API v3** (`videos.list` with `part=snippet` gives the description, 1 quota unit of 10,000/day) — it needs an API key, which only the owner can create in the Google Cloud console; without it the call is `403`. Transcripts (what is SAID in the video) are a third path (`youtube-transcript` style libraries) — not tested today.
- **Instagram and TikTok:** profile pages return HTML but the post text is behind login/JS; no API. Excluded.
- **Reddit:** every JSON endpoint is `403` from the runner and the reader is blocked; the **Atom feeds** work (`/r/pourover/top.rss?t=month`, 25 entries with the post body as HTML).
- **PDFs:** Hario's MUGEN Switch recipe PDF and Coffee Collective's guides are PDFs — `pdftotext` reads them; the scout has no PDF step today.
- **Compressed bodies:** baristamagazine.com sends gzip regardless of headers — fetch with `--compressed` or the HTML is binary.
- **Unreachable from the runner (connection fails, not a 4xx):** tricolate.com, oreaworks.com (the maker is `orea.uk`), fritz.co.kr, thecoffeechronicler.com (the live domain is `coffeechronicler.com`, which works), lancehedrick.com, jimseven.com, journal.standartmag.com.
- **Images instead of text (not scoutable):** worldaeropresschampionship.com recipe cards, Drop Coffee's guides, NextLevel Pulsar recipes, April's per-coffee recipe cards (shadow DOM), ONA's per-coffee pages.
